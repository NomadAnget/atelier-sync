公开 CI 在同一个作业内准备准确候选与私有子模块、直接运行 Python 检查、保存私有元数据回执。源码只留在 runner 临时目录，不上传源码 artifact，不使用源码缓存。测试子进程清空凭据环境变量；这不等同于操作系统级隔离。

私有域使用 coordinator 合并策略：对每个消费它的公开变体建立只改 gitlink 的草稿组合 PR；测试绑定域 head/base/merge 与变体 head/base/merge。全部组合通过且提交未变后，协调器调用带期望 head SHA 的合并 API。随后现有回流与父仓指针 PR 接续；产品 PR 重跑检查并通过平台分支规则后合并。草稿组合 PR 不合入产品主线。
